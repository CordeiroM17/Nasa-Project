
# Asteroid Simulation

A web-based interactive simulation tool to explore **asteroid impacts on Earth**. Built with **Astro**,**Python**, **Leaflet**, and modern JavaScript/TypeScript, this app allows users to visualize, manipulate, and study asteroid parameters in 2D and 3D environments.

----------

## 🌍 Main Goal

The main goal of this project is to provide an **educational and research-friendly platform** for exploring the potential effects of asteroid impacts and ways to mitigate the damage. Users can interactively select asteroids, adjust physical parameters, and simulate impacts to observe their potential consequences.

----------

## ⚡ Principal Functionalities

### 1. Asteroid Selection

-   Browse a list of real asteroids fetched from an API.
    
-   View asteroid details: name, type, diameter, density, and speed.
    
-   Automatically update simulation parameters when an asteroid is selected.
    

### 2. Adjustable Impact Parameters

-   **Asteroid Size:** Modify the diameter of the asteroid.
    
-   **Impact Speed:** Control the asteroid’s velocity.
    
-   **Impact Angle:** Adjust the angle of impact.
    
-   **Density Selection:** Choose between carbonaceous, stony, or metallic types.
    

### 3. Sidebar Menus

-   **Parameters Sidebar:** Access and adjust impact variables.
    
-   **Asteroid Menu:** Browse and select asteroids easily.
    
-   Smooth open/close animations and responsive design.
    

### 4. Interactive Map

-   Built with **Leaflet**.
    
-   Select the exact **latitude and longitude** for impact simulations.
    
-   Supports dynamic updates when parameters change.
    

### 5. Simulation

-   POSTs asteroid parameters to a backend API for impact calculations.
    
-   Displays results for size, energy, and effects of the impact.
        

### 6. 3D Simulation (Optional)

-   Link to a 3D impact simulation for more immersive visualization.
    

### 7. Localization

-   Supports multiple languages using JSON translation files.
    
-   Automatically applies the selected language on page load.
    

----------

## 🛠 Tech Stack

-   **Astro** – Static site framework for fast rendering.
    
-   **Leaflet** – Interactive 2D map visualization.
    
-   **TypeScript / JavaScript** – Dynamic UI and API interaction.
    
-   **HTML / CSS** – Layout and responsive design.
    
-   **API Integration** – Fetches asteroid data and sends impact simulations.
