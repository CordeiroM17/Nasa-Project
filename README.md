# HACKATHON NASA SPACE APP CHALLENGE - METEOR MADNESS

## FRONTEND
Antes de instalar las dependencias y correr el codigo es necesario clonar el repositorio y colocar la siguiente variable de entorno en un archivo `.env` a la misma altura que la carpeta `src`

```.env
API_URL="{URL de la api}/api"
```

Recordar que las urls pueden variar dependiendo si se encuentra en develoment o en produccion. En ambos casos deben copiar la ruta donde esta corriendo la aplicacion

Proceder a instalar las dependencias e iniciar el frontend

```.cmd
cd front end
npm install
npm run dev
```


## BACKEND
Antes de instalar las dependencias y correr el codigo es necesario clonar el repositorio y colocar la siguiente variable de entorno en un archivo `.env` a la misma altura que la carpeta `src`

```.env
API_URL="{URL de la api}"
FRONT_URL="{URL del frontend}"
NASA_API_KEY="{NASA API KEY}"
```

Recordar que las urls pueden variar dependiendo si se encuentra en develoment o en produccion. En ambos casos deben copiar la ruta donde esta corriendo la aplicacion

Proceder a instalar las dependencias e iniciar el frontend

```.cmd
cd front end
npm install

```
